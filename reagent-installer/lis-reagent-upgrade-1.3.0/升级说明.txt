试剂管理系统 升级包 v1.3.0（三方卫材对接）
=====================================================

本包只替换程序 jar 并重启服务，不改配置文件；数据库仅新增对接相关表，
不影响已有数据（脚本可重复执行）。

一、升级步骤（三选一）

  方式 1：直接执行包内脚本（推荐）
     tar -xzf lis-reagent-upgrade-1.3.0.tar.gz
     cd lis-reagent-upgrade-1.3.0
     sudo bash upgrade.sh

  方式 2：指定安装目录
     sudo bash upgrade.sh --dir /lis_reagent/lis-reagent-1.0.0

  方式 3：只替换 jar（不用脚本）
     cp app/lis-reagent.jar /lis_reagent/lis-reagent-1.0.0/app/
     systemctl restart lis-reagent

  脚本会自动完成：定位安装目录 → 校验 jar → 备份旧 jar →
  原子替换 → 重启服务 → 健康检查；检查失败自动回滚旧版本。

二、回滚

  sudo bash upgrade.sh --rollback

  或手动把 backup/lis-reagent.jar.<时间戳> 覆盖回 app/lis-reagent.jar 后重启。

三、新增功能所需数据库表（首次升级到 1.3.0 时执行一次）

  三方卫材对接使用 4 张新表，另给采购订单补 2 个字段。脚本故意不改数据库，
  请在升级后手动执行一次：

    psql -U lis_reagent -d lis_reagent -f db/add-reagent-thirdparty.sql

  脚本内全部为 CREATE TABLE IF NOT EXISTS / ADD COLUMN IF NOT EXISTS，
  可重复执行，不影响已有数据。

四、升级后使用

  1) 浏览器打开 http://<服务器IP>:8092/
  2) 进入「三方对接」菜单：
     - 三方卫材对接：维护对方接口地址、鉴权方式、接口路径、入站 Token
     - 卫材商品映射：维护本系统试剂与对方商品编码的对应关系
     - 卫材接口日志：查看出站/入站请求报文与耗时
  3) 采购订单页面新增「推送卫材」按钮，推送成功后回写对方单号。

五、注意事项

  - 升级前请确认服务器已安装 curl（用于健康检查）；未安装时会跳过检查。
  - 默认健康检查端口 8092，可在 config/application.yml 中修改 server.port。
  - 若使用 systemd，脚本自动执行 systemctl restart lis-reagent；
    未使用 systemd 时调用安装目录下的 bin/stop.sh、bin/start.sh。
