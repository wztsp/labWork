试剂管理系统 升级包 v1.3.1（试剂条码与单据打印模板）
=====================================================

本包只替换程序 jar 并重启服务，不改配置文件；数据库仅新增打印模板表，
不影响已有数据（脚本可重复执行）。

一、升级步骤（三选一）

  方式 1：直接执行包内脚本（推荐）
     tar -xzf lis-reagent-upgrade-1.3.1.tar.gz
     cd lis-reagent-upgrade-1.3.1
     sudo bash upgrade.sh

  方式 2：指定安装目录
     sudo bash upgrade.sh --dir /lis_reagent/lis-reagent-1.0.0

  方式 3：只替换 jar（不用脚本）
     cp app/lis-reagent.jar /lis_reagent/lis-reagent-1.0.0/app/
     systemctl restart lis-reagent

  脚本会自动完成：定位安装目录 -> 校验 jar -> 备份旧 jar ->
  原子替换 -> 重启服务 -> 健康检查；检查失败自动回滚旧版本。

二、回滚

  sudo bash upgrade.sh --rollback

  或手动把 backup/lis-reagent.jar.<时间戳> 覆盖回 app/lis-reagent.jar 后重启。

三、新增功能所需数据库表（首次升级到 1.3.1 时执行一次）

  打印模板使用 1 张新表 lis_print_template，并内置 7 条默认模板。
  脚本故意不改数据库，请在升级后手动执行一次：

    psql -U lis_reagent -d lis_reagent -f db/add-reagent-print-template.sql

  脚本内全部为 CREATE TABLE IF NOT EXISTS / CREATE INDEX IF NOT EXISTS /
  INSERT ... ON CONFLICT DO NOTHING，可重复执行，不影响已有数据。

四、升级后使用

  1) 浏览器打开 http://<服务器IP>:8092/
  2) 进入「系统维护 - 打印模板管理」：
     - 新建模板：选择业务类型与纸张尺寸，拖拽字段/条码/二维码/线条/表格到画布
     - 保存后可在单据页面「打印」按钮中选择模板与份数
     - 每个业务类型只有一个默认模板，打印时优先使用默认模板
  3) 试剂库存/入库页面的条码补打会优先使用「试剂条码标签」默认模板，
     未配置模板时回退到内置布局。

五、注意事项

  - 升级前请确认服务器已安装 curl（用于健康检查）；未安装时会跳过检查。
  - 默认健康检查端口 8092，可在 config/application.yml 中修改 server.port。
  - 若使用 systemd，脚本自动执行 systemctl restart lis-reagent；
    未使用 systemd 时调用安装目录下的 bin/stop.sh、bin/start.sh。
  - 打印模板内容全部为浏览器本地渲染（条码/二维码不依赖外网 CDN），
    可在完全离线的内网环境使用。
