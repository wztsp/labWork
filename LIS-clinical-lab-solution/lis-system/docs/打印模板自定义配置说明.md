## 1. 功能概述

打印模板功能把「打印什么」和「打印成什么样」从代码中剥离出来，由使用方在页面上自行配置：

- **覆盖 7 类业务**：试剂条码标签、采购申请单、采购订单、试剂入库单、领用/出库单、库存盘点单、报损单。
- **可视化拖拽设计**：全屏设计器，元素以 mm 为单位绝对定位，支持拖动、缩放、5mm 网格辅助线。
- **模板与单据解耦**：打印时按「业务类型」取模板，模板只引用统一的字段编码，不依赖具体单据结构。
- **开箱即用**：内置 7 个默认模板，安装后即可打印，也可在页面上继续编辑。
- **完全离线**：条码/二维码在浏览器本地渲染为内联 SVG，打印页不加载任何外部脚本或 CDN 资源，适用于医院内网与离线部署环境。

### 1.1 关键概念

| 概念 | 说明 |
| --- | --- |
| 业务类型（bizType） | 打印场景的分类，决定可用字段与默认模板，取值为 7 个固定编码之一 |
| 模板编码（templateCode） | 模板唯一标识，全局不重复，创建后不可修改 |
| 默认模板 | 同一业务类型下唯一的启用模板，打印时优先使用；通过「设为默认」切换 |
| 画布（canvas） | 模板的内容区，尺寸 = 纸张尺寸 − 2 × 边距 |
| 元素（element） | 画布上的一个打印对象（文本/字段/条码/二维码/线条/矩形/图片/表格），坐标单位 mm |
| 内容区 | 纸张去掉四周边距后的可打印区域，元素的 x/y 以内容区左上角为原点 |

## 2. 入口与权限

### 2.1 菜单入口

登录后，左侧菜单：

```
系统维护 → 打印模板管理
```

对应路由：`/reagent/print-template`。

### 2.2 页面结构

| 区域 | 内容 |
| --- | --- |
| 查询条件 | 业务类型下拉、状态下拉（启用/停用）、关键词（模板编码/名称） |
| 列表工具栏 | 「新建模板」按钮 |
| 列表列 | 模板编码、模板名称、业务类型、纸张(mm)、默认、状态、更新时间、操作 |
| 操作列 | 设计、设为默认、复制、停用/启用、删除 |

操作按钮的可用规则：

- **设为默认**：仅对「启用」且非默认的模板可用。
- **停用/启用**：默认模板不可停用。
- **删除**：默认模板不可删除（需先把其他模板设为默认）。
- **复制**：生成新编码 `原编码_COPY_随机三位`，名称为「原名（副本）」，默认值清零、状态置为启用，可直接在设计器中修改后保存。

### 2.3 权限

打印模板管理随系统登录鉴权（默认开启登录，账号密码可在 `application.yml` 的 `app.login` 中配置）。如需限制到特定角色，可在网关/菜单权限层控制该路由的可见性；后端接口本身不额外做角色校验。

## 3. 业务类型与字段字典

字段字典由后端统一维护（`PrintFieldCatalog`），设计器左侧「表头字段 / 明细字段」面板即来源于此，保存时字段编码必须与字典一致。

每个业务类型包含三组字段：

| 分组 | 用途 | 在设计器中的使用方式 |
| --- | --- | --- |
| `header` 表头 | 单据主信息 | 点击字段生成「字段」元素，或在文本中用 `{{字段}}` 插值 |
| `items` 明细 | 单据明细行 | 点击字段向选中的表格追加一列 |
| `meta` 公共 | 打印时间 | 所有业务类型统一为 `printTime` |

> 所有字段的取值均为字符串（空值输出为空串），金额/数量已在后端格式化为可打印文本。

## 4. 设计器使用

点击列表中的「设计」（或「新建模板」）打开全屏设计器，布局为：顶部工具栏 + 左侧元素/字段面板 + 中间画布 + 右侧属性面板。

### 4.1 顶部工具栏

| 控件 | 说明 | 取值范围 / 默认 |
| --- | --- | --- |
| 模板名称 | 必填 | 最多 128 字符 |
| 模板编码 | 必填，全局唯一；**编辑已有模板时禁用** | 最多 64 字符；新建时自动生成 `业务类型_四位随机数` |
| 业务类型 | 必填；**编辑已有模板时禁用** | 7 类之一 |
| 设为默认 | 勾选后保存即成为该业务的默认模板（同业务其他模板自动取消默认） | 默认不勾选 |
| 纸张预设 | 选择后自动带出宽高 | 见第 7 章 |
| 宽 / 高 | 纸张尺寸，单位 mm | 20 ~ 460，步长 1 |
| 边距 | 四周等边距，单位 mm | 0 ~ 60，步长 0.5 |
| 缩放 | 设计视图缩放比例 | 25% ~ 200%，另有「适应宽度」自动计算（20% ~ 200%，5% 取整） |
| 网格 | 显示 5mm 网格辅助线（仅显示，不吸附） | 默认开启 |
| 预览 | 用占位数据按纸张实际尺寸打开新窗口 | — |
| 保存 | 校验通过后提交后台 | — |
| 关闭 | 放弃本次修改 | — |

新建模板时的默认纸张：

| 业务类型 | 纸张 | 边距 | 画布（内容区） |
| --- | --- | --- | --- |
| `REAGENT_LABEL` | 60 × 40 mm | 2 mm | 56 × 36 mm |
| 其余 6 类 | 210 × 297 mm（A4） | 8 mm | 194 × 281 mm |

新建时会自动在画布顶部插入一个居中、加粗、20px 的标题文本（内容为业务类型名称），可直接修改。

### 4.2 左侧面板

- **元素按钮**：文本、条码、二维码、线条、矩形、表格、图片。点击后元素追加到画布下方（自动避开已有元素，纵向留 2mm 间距），并立即选中。
- **表头字段**：点击任一字段，生成一个已绑定该字段的「字段」元素（宽 = 内容区宽，高 6mm，字号 10px，标签宽度按中文名长度估算 10~24mm）。
- **明细字段**：必须先**在画布中选中表格元素**，再点击字段，向该表格追加一列；未选中表格时会提示「请先在画布中选中表格元素，再点击明细字段追加列」。
- 明细字段列表首项固定为 `index`（序号），可按整份单据连续编号。

### 4.3 画布操作

| 操作 | 说明 |
| --- | --- |
| 拖动位置 | 在元素上按住鼠标左键拖动，坐标按 0.5mm 取整，不允许出现负坐标 |
| 调整尺寸 | 拖动选中元素右下角的蓝色控制点，宽高按 0.5mm 取整；线条元素高度可为 0 |
| 选中 | 单击元素；单击画布空白处取消选中 |
| 删除 | 右侧属性面板标题行的「删除」 |
| 缩放 | 顶部「缩放」下拉或「适应宽度」；缩放只影响设计视图，不影响打印尺寸 |

### 4.4 右侧属性面板

顶部显示「位置与尺寸（mm）」四个输入框 `x / y / w / h`（步长 0.5，x/y 最小 0，w 最小 0.5），下方按元素类型显示专属属性（见第 5 章）。

### 4.5 预览

设计器的「预览」不是真实单据数据，而是按字段中文名生成的占位数据：

- 普通字段显示 `【字段中文名】`；
- `barcode` 显示 `RG202610290001`；
- `printTime` 显示 `2026-10-29 10:00:00`；
- 表格只渲染表头 + 3 行示例。

预览会按模板纸张尺寸打开独立窗口，用于核对布局、字号、条码宽度，不会真正打印。

### 4.6 保存校验

保存时依次校验，任一不满足会给出提示且不提交：

1. 模板编码、模板名称、业务类型必填；
2. 至少包含 1 个元素；
3. 后端再校验：业务类型合法、编码唯一、模板 JSON 合法（必须是 JSON 对象且含 `elements` 数组）、纸张宽高 > 0。

## 5. 元素类型与属性

所有元素共有属性：

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 元素唯一标识，设计器自动生成 |
| `type` | enum | `text` / `field` / `barcode` / `qrcode` / `line` / `rect` / `image` / `table` |
| `x` / `y` | number | 相对内容区左上角的坐标，单位 mm |
| `w` / `h` | number | 宽高，单位 mm |

各类型专属属性：

| 类型 | 属性 | 说明 |
| --- | --- | --- |
| `text` 文本 | `text` | 文本内容，支持 `{{字段}}` 插值；可换行 |
| | `fontSize` | 字号，单位 **px**，范围 5~72，默认 10 |
| | `bold` | 是否加粗 |
| | `align` | `left` / `center` / `right` |
| | `color` | 文字颜色，默认 `#000` |
| `field` 字段 | `field` | 绑定的表头字段编码（必须来自字段字典） |
| | `label` | 前缀标签文字，如「试剂」「批号」；留空则不显示 |
| | `labelWidth` | 标签占宽，单位 mm；值区域自动占满剩余宽度 |
| | `fontSize` / `bold` / `color` | 同文本 |
| `barcode` 条码 | `value` | 条码内容，支持 `{{字段}}`，默认 `{{barcode}}` |
| | `symbology` | 固定 `CODE128`（不可更改） |
| | `showText` | 是否显示可读字符，默认显示 |
| `qrcode` 二维码 | `value` | 二维码内容，支持 `{{字段}}`，默认 `{{barcode}}` |
| `line` 线条 | `thickness` | 线宽，单位 mm，0.1~5，默认 0.3 |
| | `color` | 线条颜色 |
| `rect` 矩形 | `thickness` | 边框线宽，单位 mm，0.1~5，默认 0.3 |
| | `color` | 边框颜色 |
| `image` 图片 | `src` | 图片内容，保存为 DataURL；**单张不超过 100KB**，建议 PNG |
| `table` 表格 | `rowHeight` | 行高，单位 mm，4~20，默认 8 |
| | `columns` | 列数组：`field`（明细字段编码或 `index`）、`title`（表头文字）、`width`（列宽 mm）、`align`（`left`/`center`/`right`） |

### 5.1 渲染规则与注意事项

- **文本**：`{{字段}}` 只从表头字段与 `printTime` 取值，不支持明细字段；变量名只允许字母、数字、下划线。值会做 HTML 转义，`<`、`&` 等字符不会破坏版式。
- **字段**：直接读取表头同名字段，不做插值；字段值为空时只显示标签。
- **条码**：CODE128 仅支持 ASCII 字符（数字、字母、常用符号）。内容为空或含无法编码的字符（如中文）时，该条码**静默不显示**，不会导致整页打印失败；需要打印中文请使用二维码或文本。
- **二维码**：支持中文与任意文本，纠错级别 M，自动选择版本，按元素框等比缩放。
- **线条**：设计器中常把 `h` 设为 0，渲染时容器高度取 `max(thickness, h)`，避免被溢出裁剪。
- **矩形**：以 `thickness` 作为四边框线宽绘制，内部透明。
- **图片**：按 `object-fit: contain` 等比缩放，不拉伸。
- **表格**：表头浅灰底加粗居中，单元格 10px、单行不换行、超出省略；列宽之和建议等于内容区宽度，超出会被裁剪。

## 6. 模板 JSON 结构与坐标体系

模板在数据库中以 JSON 文本存储（`lis_print_template.template_json`），设计器负责生成，通常无需手工编辑。

### 6.1 结构

```json
{
  "version": 1,
  "canvas": { "width": 194, "height": 281, "background": "#ffffff" },
  "elements": [
    {
      "id": "t1",
      "type": "text",
      "x": 0,
      "y": 0,
      "w": 194,
      "h": 10,
      "text": "试剂采购申请单",
      "fontSize": 20,
      "bold": true,
      "align": "center",
      "color": "#000000"
    },
    {
      "id": "tb1",
      "type": "table",
      "x": 0,
      "y": 35,
      "w": 194,
      "h": 130,
      "rowHeight": 8,
      "columns": [
        { "field": "index", "title": "序号", "width": 10, "align": "center" },
        { "field": "reagentCode", "title": "试剂编码", "width": 28, "align": "left" },
        { "field": "reagentName", "title": "试剂名称", "width": 50, "align": "left" },
        { "field": "specification", "title": "规格", "width": 38, "align": "left" },
        { "field": "quantity", "title": "数量", "width": 18, "align": "right" },
        { "field": "unit", "title": "单位", "width": 14, "align": "center" },
        { "field": "estimatedPrice", "title": "预估单价", "width": 18, "align": "right" },
        { "field": "amount", "title": "金额", "width": 18, "align": "right" }
      ]
    },
    { "id": "ft1", "type": "text", "x": 0, "y": 262, "w": 194, "h": 6, "text": "打印时间：{{printTime}}", "fontSize": 9, "align": "center" }
  ]
}
```

### 6.2 坐标与尺寸约定

- 元素坐标单位为 **mm**，原点为**内容区左上角**（即已扣除纸张边距）。
- 内容区尺寸 = `paper_width − 2 × margin`、`paper_height − 2 × margin`。
- 渲染时页面容器为 `纸张宽高`，`padding = margin`，画布占满内容区；因此元素只要落在内容区内就能完整打印。
- `canvas.width / height` 仅作记录，**不参与排版**；实际可打印范围由纸张与边距决定（`canvas.background` 生效）。
  - 设计器保存时写入的是内容区尺寸（如 A4 + 8mm 边距 → 194 × 281）；
  - 内置默认模板的 JSON 中记录的是纸张尺寸（如 210 × 297），两者渲染结果一致，无需手工修改。
- 超出内容区的元素会被 `overflow: hidden` 裁剪，请在设计器中用「预览」核对。

### 6.3 分页规则

- 每个表格元素独立计算单页容量：`capacity = floor(h / rowHeight) − 1`（预留一行表头）。
- 单据总页数 = 所有表格中 `ceil(明细行数 / capacity)` 的最大值，最少 1 页。
- 每一页都重复渲染表头；明细逐页切片。
- `index`（序号）列按整份单据连续编号，跨页不重置。
- 例：表格 `h=130`、`rowHeight=8` → 每页 16 行；45 条明细 → 3 页（16 / 16 / 13 行）。
- 打印份数 `copies` 为**整份重复**：先将全部数据页渲染完，再整体重复 N 次。

- 打印 HTML 内联全部样式与 SVG，无外部请求，断网/离线环境可正常出纸。

## 10. 条码标签打印与补打

### 10.1 使用场景

| 页面 | 入口 | 说明 |
| --- | --- | --- |
| 入库验收 | 「打印条码（N）」 | 打印本次验收已生成条码的明细，一码一标签 |
| 试剂库存 | 批次行「补打」 | 对已有批次条码重新打印 |

### 10.2 模板选择逻辑

1. 取 `REAGENT_LABEL` 业务类型下**启用的默认模板**；未设默认时取第一条启用模板；
2. 若模板 JSON 无法解析或该业务下无模板，回退到**内置标签布局**（沿用 `reagent-barcode` 场景打印配置：60×40mm、边距 2mm、字号 9px、条码高约 26px）；
3. 无论走模板还是内置布局，条码都在父窗口预渲染为 SVG，打印页零外部依赖。

### 10.3 标签数据字段

标签打印数据由前端本地组装（不调用单据打印数据接口），可用字段见 3.1，其中：

- `barcode`：批次条码（如 `RG` + 试剂ID + 批号 + 明细ID 规则生成）；
- 入库单号、采购订单号、供应商三项会按出现顺序映射到 `inboundNo`、`orderNo`、`supplierName`；
- 明细数组固定 1 行，因此标签模板不需要表格元素。

### 10.4 建议配置

- 标签模板只用「字段」+「条码」元素，避免放表格；
- 条码元素宽度建议 ≥ 40mm，高度 10~14mm，否则条宽过密影响扫码率；
- 若使用热敏标签打印机，请在驱动中把纸张设为 60×40（或实际标签规格），边距设为 0，模板边距用 1~2mm 即可。

## 12. 数据库与部署升级

### 12.1 表结构

表名：`lis_print_template`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | BIGSERIAL | 主键 |
| `template_code` | VARCHAR(64) NOT NULL | 模板编码，唯一 |
| `template_name` | VARCHAR(128) NOT NULL | 模板名称 |
| `biz_type` | VARCHAR(32) NOT NULL | 业务类型编码 |
| `paper_width` | DECIMAL(6,1) NOT NULL | 纸张宽 mm，默认 210 |
| `paper_height` | DECIMAL(6,1) NOT NULL | 纸张高 mm，默认 297 |
| `margin` | DECIMAL(5,1) NOT NULL | 边距 mm，默认 5 |
| `template_json` | TEXT NOT NULL | 画布与元素定义 JSON（mm 坐标） |
| `is_default` | SMALLINT NOT NULL | 0 否 / 1 是该业务默认模板 |
| `status` | SMALLINT NOT NULL | 0 停用 / 1 启用 |
| `remark` | VARCHAR(500) | 备注 |
| `create_by` / `create_time` | VARCHAR(50) / TIMESTAMP | 创建人 / 创建时间 |
| `update_by` / `update_time` | VARCHAR(50) / TIMESTAMP | 修改人 / 修改时间 |

索引与约束：

| 名称 | 类型 | 作用 |
| --- | --- | --- |
| `uk_lis_print_template_code` | 唯一索引 | 模板编码全局唯一 |
| `uk_lis_print_template_default` | 部分唯一索引：`(biz_type) WHERE is_default = 1 AND status = 1` | 同一业务类型只允许一个启用的默认模板 |
| `idx_lis_print_template_biz` | 普通索引：`(biz_type, status)` | 按业务类型/状态查询 |

> 默认模板的唯一性由「业务层先清零其他默认 + 数据库部分唯一索引兜底」共同保证；并发切换默认模板时不会出现两个默认。

### 12.2 初始化脚本

脚本路径：`lis-system/docs/database/add-reagent-print-template.sql`

- 全部语句幂等：建表/索引使用 `IF NOT EXISTS`，种子数据使用 `ON CONFLICT (template_code) DO NOTHING`；
- 可重复执行，不会覆盖已被修改的模板；
- 执行方式（二选一）：
  - 使用 DBA 工具（Navicat / DBeaver / pgAdmin）对业务库执行整个脚本；
  - 命令行：`psql -h <host> -p 5432 -U <user> -d <db> -f add-reagent-print-template.sql`

> 若数据库连接串未带 `characterEncoding=utf8`，中文模板名称/内容可能写入乱码，请确认 JDBC 连接参数已包含该设置。

## 13. 常见问题（FAQ）

**Q1：为什么「删除」按钮是灰的？**
默认模板不可删除。请先把同业务类型下的其他模板「设为默认」，再删除原模板。后端同样会拦截并提示「默认模板不可删除，请先将其他模板设为默认」。

**Q2：为什么「设为默认」按钮是灰的？**
该模板已停用，或本身已是默认。停用模板不能设为默认，需先「启用」。

**Q3：模板编码可以修改吗？**
不可以。编码是模板唯一标识，编辑时输入框禁用且后端按编码判重；需要改编码请用「复制」生成新模板。

**Q4：保存时提示「模板内容不是合法的 JSON」/「模板内容缺少 elements 数组」怎么办？**
通常发生在手工修改数据库或接口直调时。请用设计器重新保存；如为接口调用，确保 `templateJson` 是字符串形式的对象，且包含 `elements` 数组。

**Q5：条码打印出来是空白？**
条码内容为空或包含 CODE128 无法编码的字符（如中文、全角符号）。请改为纯数字/字母，或改用二维码；条码渲染失败时会静默跳过，不会影响整页其他内容。

**Q6：预览/打印没有反应，或提示「无法打开打印窗口」？**
浏览器拦截了新窗口。请在浏览器地址栏的弹窗拦截提示中允许该站点，或将系统地址加入白名单后重试。

**Q7：明细很多时表格被截断？**
表格的每页容量由 `表格高度 ÷ 行高 − 1` 决定，超出部分会自动分页并在每页重复表头，不会丢失数据。若页数过多，可适当增大表格高度或减小行高。

**Q8：打印出来的纸张大小不对、内容被缩放？**
两个原因：① 模板纸张与实际打印机纸张不一致；② 打印机驱动勾选了「适应页面/缩放」。请在驱动中选择与模板一致的纸张规格并关闭缩放。

**Q9：为什么标签打印没有走我新建的模板？**
标签打印固定取 `REAGENT_LABEL` 业务类型下的默认模板。请确认新模板的业务类型为「试剂条码标签」、状态为启用，并已「设为默认」。

**Q10：`REAGENT_LABEL` 调用 `/print-data/...` 报「不支持的业务类型」？**
属正常设计。标签数据由前端在入库验收/库存补打时本地构造，不经过单据打印数据接口。

**Q11：同一业务类型能有多个启用模板吗？**
可以。打印弹窗会列出全部启用模板供选择，但只有其中一个能是默认模板（数据库部分唯一索引限制）。

**Q12：模板可以放图片（如医院 LOGO）吗？**
可以，图片以 DataURL 存入模板 JSON，单张不超过 100KB。图片越大模板 JSON 越大，建议先压缩为 PNG。

**Q13：能否让表格的「序号」在每页从 1 开始？**
目前 `index` 固定按整份单据连续编号（跨页不重置），这是为避免多页单据出现重复序号。如需每页重置，可自建一个不绑定 `index` 的普通列，由业务侧另行处理。
