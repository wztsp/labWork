# LIS 系统启动脚本使用说明

## 文件列表

| 文件 | 功能 |
|------|------|
| `start.ps1` | PowerShell 启动脚本 (核心) |
| `stop.ps1` | PowerShell 停止脚本 (核心) |
| `启动系统.bat` | 双击启动 (推荐) |
| `停止系统.bat` | 双击停止 (推荐) |

## 快速开始

### 方式一：双击运行 (推荐)

1. 双击 `启动系统.bat`
2. 等待启动完成，看到访问地址后即可使用
3. 停止时双击 `停止系统.bat`

### 方式二：PowerShell 命令

```powershell
# 启动 (需要以管理员权限运行)
powershell.exe -ExecutionPolicy Bypass -File .\start.ps1

# 停止
powershell.exe -ExecutionPolicy Bypass -File .\stop.ps1

# 跳过 Maven 构建 (仅当 JAR 已存在时)
powershell.exe -ExecutionPolicy Bypass -File .\start.ps1 -SkipBuild
```

## 启动流程

1. **环境检查** - 验证 Java 17+、Node.js 18+ 是否安装
2. **后端构建** (首次或源码变更时) - 执行 Maven 打包
3. **端口检查** - 检测 8080/3000 端口是否被占用
4. **启动后端** - 运行 Spring Boot 单体应用 (包含 TCP 仪器通信)
5. **启动前端** - 运行 Vite 开发服务器
6. **等待就绪** - 自动检测服务端口监听状态

## 服务端口

| 服务 | 端口 | 说明 |
|------|------|------|
| 前端 (Vite) | 3000 | http://localhost:3000 |
| 后端 API | 8080 | http://localhost:8080 |
| TCP 仪器通信 | 9100 | TCP 协议 |

## 日志文件

启动后日志保存在项目根目录 `logs/` 文件夹：

| 文件 | 说明 |
|------|------|
| `backend.log` | 后端服务标准输出 |
| `backend-error.log` | 后端服务错误日志 |
| `frontend.log` | 前端服务标准输出 |
| `frontend-error.log` | 前端服务错误日志 |
| `processes.json` | 进程信息 (PID、端口等) |

## 常见问题

### Q: 提示 "未检测到 Java 环境"
安装 JDK 17 或更高版本，并配置 JAVA_HOME 环境变量。

### Q: 提示 "未检测到 Node.js 环境"
安装 Node.js 18 或更高版本，并添加到 PATH。

### Q: 端口被占用
脚本会自动提示并询问是否释放端口，选择 Y 即可自动终止占用进程。

### Q: 启动后无法访问页面
1. 检查 `logs/backend-error.log` 查看后端错误
2. 检查 `logs/frontend-error.log` 查看前端错误
3. 确认 PostgreSQL 数据库服务已启动
4. 确认 Redis 服务已启动 (可选)

### Q: 如何修改端口
编辑 `start.ps1` 文件开头的配置区域：
```powershell
$BackendPort = 8080
$FrontendPort = 3000
$TcpPort = 9100
```

## 依赖服务

启动前请确保以下服务已运行：

- ✅ **PostgreSQL** - 数据库 (端口 5432)
- ⚪ **Redis** - 缓存 (可选，端口 6379)
- ⚪ **RabbitMQ** - 消息队列 (可选，端口 5672)
